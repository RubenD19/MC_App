# Maple Clinic Mobile App

## Overview

This app has been developed to make it more accessible for patients to contact their clinic. Instead of having to open a website and navigate to their required action, the app provides a simple, straightforward and fast way for the patient to do so.

### Development

The frontend has been developed using [React Native](https://reactnative.dev/) and [Expo](https://expo.dev).

## Features:

- Request an appointment
- Renew prescriptions
- Request a copy of certification


## Run the Mobile App

```bash
cd frontend
npm install
npx expo start
```
